# 量潮 DevOps 工作意图

记录工作意图：当前正在做什么、为什么要做、做到什么程度算完成。

## 形式化描述

每节正文之后，紧跟一段以「形式化。」起手的段落，把这一节的自然语言收成**可判定的陈述**。

四条要求：

- **收窄，不是重述。** 散文里说「更好」「更多」「更快」，形式化段要给出可比较的量。
  例：「对外开放是社会价值产生的前提」→「$V$ 随 $K$ 与 $S$ 的质量单调增加」。
- **给符号，给关系。** 用行内 LaTeX 定下变量，再给约束、目标或更新式。
  例：「最大化 $V$，约束 $R \ge C$」；「$x' = F(x, b)$」。
- **可判定。** 读完这段要能回答「怎么算达标」——能观测、能比较、能证伪。
  例：「判据即 $J(x) = \mathbb{E}[d(q, x)]$ 逐期下降」。
- **一段。** 单独成段，不铺开成新的一节。

正文负责说清「为什么」和「是什么」，形式化段负责把同一件事收成「怎么算数」。
**一段形式化如果只是把正文换个说法，那它没在做事。**
